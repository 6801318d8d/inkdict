# Flags

The flags of the dictionary list in the main README, one per language code (`<code>.svg`), shown as images so that
they look the same in every browser (Chrome and Edge on Windows show flag emoji as two letters).

- From [flag-icons](https://github.com/lipis/flag-icons) 7.2.3, 4x3 version, MIT license (`LICENSE_flag_icons`),
  renamed from the country code to the language code: `bg` Bulgaria, `ca` Catalonia, `cs` Czechia, `da` Denmark,
  `de` Germany, `el` Greece, `en` United Kingdom, `es` Spain, `eu` Basque Country, `fi` Finland, `fr` France,
  `it` Italy, `ja` Japan, `ko` South Korea, `la` Vatican City, `lt` Lithuania, `mg` Madagascar, `nl` Netherlands,
  `no` Norway, `pl` Poland, `pt` Portugal, `ro` Romania, `ru` Russia, `sv` Sweden, `th` Thailand, `tr` Turkey,
  `uk` Ukraine, `zh` China.
- `eo`: the flag of Esperanto, from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Flag_of_Esperanto.svg)
  (public domain).

A language without a file here (Lojban) gets 🌐.
